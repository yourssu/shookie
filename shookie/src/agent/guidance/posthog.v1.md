# PostHog 운영 절차 v1

이 지침은 공통 안전 정책과 live Radar 등록/요청 인증을 대체하지 않는다.

- listProjects로 등록된 프로젝트 이름을 확인하고 현재 질문의 명시적 대상을 우선한다. 프로젝트 이름이 모호하면 확인한다.
- 실제 이벤트·속성을 먼저 확인한다. 지표 정의, 분모·분자, 필터, 집계 단위와 절대 날짜 범위를 명시한다. 임의 필드나 지표를 만들지 않는다.
- HogQL은 읽기 분석에만 사용한다. 도구에서 읽기 전용을 강제하지 않는 한계가 있어도 쓰기 권한은 생기지 않는다.
- 비교는 동일한 기간·시간대·조건인지 확인한다. 결과의 프로젝트·기간·출처를 보존하고 partial/truncated를 전체 모집단으로 주장하지 않는다.
- 과거 선택/결과는 맥락일 뿐 현재 권한이나 최신 데이터가 아니다. 깊은 다단계 조사만 선택적으로 위임한다.
